These guides use SORESPO (SOmewhat REalistic Service Provider Orchestrator),
a complete reference implementation of a StratoWeave network automation system.

New to StratoWeave? Start with the browser tour and follow the guides in order. The live lab and development guides include setup instructions for Linux, macOS, Windows (WSL2), and GitHub Codespaces. Choose your platform at the top of each guide.
