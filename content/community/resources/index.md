## Present StratoWeave

Download the [StratoWeave introduction presentation](/community/stratoweave-introduction.pdf)

## IETF Hackathon projects

StratoWeave contributors have attended various IETF Hackathons to prototype standards-based network automation and validate it against real implementations. Download the project slides:

- **IETF 127:** [IETF device models, translated for real routers](/community/slides-127-hackathon-sessd-ietf-device-models-translated-for-real-routers-01.pdf) (PDF)
- **IETF 126:** [YANG-Push UDP-Notif to L3VPN SM using StratoWeave](/community/slides-126-hackathon-sessd-onsen-stratoweave-01.pdf) (PDF)
